## 今の見た目が AI 的に見える理由（見立て）

| 今の作り | なぜありきたりに見えるか |
|---|---|
| プレイヤー・敵・床が、単色の四角（敵は白い四角の目が2つ） | 形に個性がなく、仮置きの図形に見える |
| 背景は、左右対称の半円の丘と、明るい単色の空 | どの面も同じ作りで、場所の空気がない |
| 影・輪郭・光の向き・質感がない | 平らで、手で描いた跡がない |
| 効果は半透明の円（glow）を重ねるだけ | よくある「光らせておけばよい」演出 |
| 画面の文字は標準のゴシック体、アイコンは絵文字（📲 ⚔ ⏸） | 道具の既定のままに見える |
| 色は面ごとに明るさをそろえたパステル | 強弱がなく、どの色も同じ重さ |

## テーマを描くときの決まり

- HTML 1枚。画像ファイル・外部のフォント・外部のライブラリを使わない（ゲームと同じく Canvas 2D のコードで描く。選んだテーマをそのままゲームへ移すため）。フォントは Mac・iPhone・Android にあるものだけ（例：`Hiragino Mincho ProN`・`Hiragino Sans`・`serif`・`sans-serif`・`monospace`）。
- 毎回同じ絵になるようにする（`Math.random` ではなく種の決まった乱数）。
- 1フレーム 16ms の中で描ける重さにする（紙の目・網点などの質感は、最初に1回だけ別の canvas に描いて使い回す）。
- 描く部品を関数に分ける：`drawSky`・`drawFar`（遠景）・`drawGround`・`drawPlatform`・`drawPlayer`・`drawEnemy`・`drawHeart`・`drawFlag`・`drawHUD`。
- 絵文字を使わない。画面の文字は日本語。
